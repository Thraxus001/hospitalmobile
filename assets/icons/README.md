# Icons Folder

Place your custom icon images here. Supported formats: `.png`, `.svg`, `.jpg`

## Expected icons (name them exactly as listed):
- `logo.png` – App logo (used on landing page & login)
- `hero-banner.png` – Hero image for landing page
- `doctor-banner.png` – Doctor/health banner for dashboard
- `home.png` – Tab bar home icon
- `appointments.png` – Tab bar appointments icon
- `profile.png` – Tab bar profile icon
- `cardiology.png` – Cardiology department image
- `neurology.png` – Neurology department image
- `pediatrics.png` – Pediatrics department image
- `orthopedics.png` – Orthopedics department image

The app will automatically use these images once placed here.
